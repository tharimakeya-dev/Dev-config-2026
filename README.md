# AI Prompt(s) Used

## Prompt

Create a unique HTML and CSS section for a DevConf 2026 conference website.

The section should be named "Career Zone".

Requirements:
- Use only HTML and CSS.
- Create three modern cards:
  - Job Fair
  - Internship Hub
  - Portfolio Review
- Add a responsive layout.
- Add a simple hover effect where each card changes to a dark background and moves slightly upward.
- Include a blue button labeled "Explore Opportunities".
- Keep the design clean and consistent with a professional developer conference website.

## AI Usage

I used ChatGPT to generate the initial idea and HTML/CSS code. After that, I customized the content, styling, spacing, and hover effects to match my DevConf 2026 website.
